# BRich Platform

Web comercial de BRich System y, próximamente, portal privado de clientes.

## Estado
- **Etapa 1 (web comercial):** inicio + páginas de los 3 sistemas. El formulario valida datos pero todavía **no los envía**.
- Etapa 2: login y dashboard (Supabase).
- Etapa 3: formulario → n8n → Supabase.

## Publicar en Vercel
1. Entra a vercel.com → **Add New → Project**.
2. Elige el repositorio `brich-platform` → **Deploy**. No hace falta cambiar ninguna opción.

## Trabajar en local
```bash
npm install
npm run dev   # abre http://localhost:3000
```
